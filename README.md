# 🎂 Happy Birthday, Sonali ❤️
A birthday surprise website for **Jannatul Ferdous Sonali** — built with love, code,
candles & an unmeasurable amount of affection. 🌹

> **Live at:** https://tamjid0x01.github.io/Happy-brithday-Sonali/

## ✨ What's inside

- 🎁 An "open your surprise" gift box intro with a confetti burst
- 💖 A dreamy hero with animated gradients, twinkling stars, floating hearts & balloons
- 💌 A typewriter love letter written from a husband's heart
- 📸 Sonali's photo as a 3D-tilting polaroid
- 💝 "Why my heart picks you" flip cards
- 🎂 A CSS birthday cake — tap each flame to blow out the candles & grant a wish
- 🕰️ "Our little forever" timeline
- ❤️ A pulsing-heart finale with replayable confetti
- 🎵 A synthesized *Happy Birthday* melody (pure Web Audio — no audio files needed)

## 🛠 Tech

- Vanilla HTML5 / CSS3 / JavaScript (no frameworks, no dependencies)
- Google Fonts: Playfair Display · Caveat · Poppins
- Web Audio API for the melody, Canvas for confetti, IntersectionObserver for reveals
- Fully responsive, with `prefers-reduced-motion` support
